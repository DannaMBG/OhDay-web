# OhDay - Tu agenda inteligente que se adapta a ti

Página web oficial de OhDay, el primer gestor de actividades con reprogramación inteligente, rutinas flexibles y gamificación integrada.

## 🚀 Características

- **Diseño moderno y responsive**: Adaptado para todos los dispositivos
- **Navegación suave**: Scroll suave entre secciones
- **Animaciones**: Efectos de entrada y transiciones suaves
- **Optimizado**: Carga rápida y rendimiento optimizado

## 📁 Estructura del Proyecto

```
OhDay/
├── index.html      # Estructura HTML principal
├── styles.css      # Estilos CSS modernos
├── script.js       # JavaScript para interactividad
└── README.md       # Documentación del proyecto
```

- **Google Fonts** - Tipografía Inter

## 📱 Responsive Design

La página está completamente optimizada para:
- 📱 Móviles (320px+)
- 📱 Tablets (768px+)
- 💻 Desktop (1024px+)
- 🖥️ Pantallas grandes (1200px+)

## 🚀 Cómo usar

1. Abre `index.html` en tu navegador
2. O sirve los archivos con un servidor local:
   ```bash
   # Con Python
   python -m http.server 8000
   
   # Con Node.js (http-server)
   npx http-server
   ```
